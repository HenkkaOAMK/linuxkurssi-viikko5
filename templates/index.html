Week 5 Documentation

Introduction

This project was completed as the Week 5 assignment of the Linux course. The goal was to create a web chat application that communicates with a locally hosted language model running on the server. The application stores conversation history in MariaDB and is automatically deployed using GitHub Actions.

CI/CD Pipeline

GitHub Actions performs linting, automated testing and deployment. Every push and pull request runs Ruff and Pytest. After successful tests, changes are automatically deployed to the cPouta server. Deployment is verified through the /viikko5/health endpoint which returns the current Git commit SHA.

Users and Permissions

A dedicated Linux user called chatapp was created for the application. A dedicated MariaDB database and database user called chatapp were created for storing chat messages. Secrets are stored in: /etc/chatapp/chatapp.env The file is readable only by root and the chatapp group.

Nginx Configuration

The application was added to the existing Nginx configuration using: /etc/nginx/snippets/chatapp.conf Previous weekly assignments remained unchanged. The following include line was added to the existing Nginx configuration: include snippets/chatapp.conf;

Model Selection

The Ollama model used is qwen2.5:0.5b. This model was selected because it has relatively small hardware requirements while still producing useful responses.

Replication

The application was installed on Server A because chat messages must be written to MariaDB. Server B remains a read-only replica from Week 4 and therefore cannot be used as the primary chat server.

Problem Solved

One problem encountered during the project was configuring GitHub Actions to connect to the cPouta server. Several deployment attempts failed because of incorrect SSH key and host verification configuration. The issue was solved by creating a dedicated deployment key, updating GitHub Secrets and verifying the SSH connection manually before retrying the deployment.

What I Learned

This project helped me understand how CI/CD pipelines work in practice. I learned how GitHub Actions, SSH deployment, Nginx, Gunicorn, MariaDB and a local language model can be combined into a working web application.
