Request Path

Browser -> Nginx -> Gunicorn -> Flask -> Ollama & MariaDB

CI/CD Pipeline

  • Ruff lint checks run automatically.
  • Pytest tests run automatically.
  • Shell scripts are syntax checked.
  • Successful pushes to main goes automatically.
  • Deployment is verified through /viikko5/health.

The pipeline successfully completed multiple deployments during development. Failed workflows prevented deployment when errors were found.

Users, Database and Secrets

The application runs as Linux user chatapp. A dedicated MariaDB database and user named chatapp were created for the application.

Secrets are stored in: /etc/chatapp/chatapp.env

Nginx Configuration

The application was added using a separate Nginx snippet:/etc/nginx/snippets/chatapp.conf
