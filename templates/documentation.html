Linux Week 5 Documentation

Introduction

This project was completed as the Week 5 assignment of the Linux course.

The goal was to create a web chat application which communicates with a locally hosted language model running on the server.

Conversation history is stored in MariaDB and deployment is handled automatically by GitHub Actions.

CI/CD Pipeline

GitHub Actions is used for continuous integration and deployment.

  • Ruff lint checks run automatically.
  • Pytest automated tests run automatically.
  • Shell scripts are syntax checked.
  • Successful pushes to main are deployed automatically.
  • Deployment is verified through the /viikko5/health endpoint.

Nginx Configuration

The application was added to the existing website using:

/etc/nginx/snippets/chatapp.conf

The following include line was added to the existing Nginx configuration:

include snippets/chatapp.conf;

Previous weekly assignments remain operational.

Model Selection

Selected model:

qwen2.5:0.5b

The model was selected because it has low memory requirements and runs well on the available server resources.

Replication

The application was installed on Server A because chat messages require database write access.

Server B remains a read-only MariaDB replica from Week 4.

Problem Solved

Several deployment attempts initially failed because of SSH deployment key and GitHub Actions configuration issues.

The problem was solved by creating a dedicated deployment key and correcting the GitHub Secrets configuration.

What I Learned

This assignment helped me understand how CI/CD pipelines work in practice.
